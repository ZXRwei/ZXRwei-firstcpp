常量定义语法：
（运行时常量：运行后得值，可在运行中获值）
const 类型 常量名 { 值 }；
（编译时常量：编译时得值，不可在运行中获值）
constexpr 类型 常量名 { 值 }；

//x为int类型，数值为1的编译时常量；
constexpr int x{ 1 };
{
	//a为int类型，数值为2的变量；
	int a{ 2 };
	//b为int类型，数值为3的运行时常量；
	const int b{ 3 };
}


自动推导类型：auto
auto 变量名 { 初始值 }；
挂常量前会使常量变成普通变量：
{
	//定义 a 为常量，值为 1 ；
	const int a{ 1 };
	//auto赋值后 b 为变量；
	auto b{ a };
	//可在auto前重新挂const将 b 变为常量（constexpr同样支持）；
	const auto b{ a };
}

强制转换：
（数值类型）变量名
{
	//a1为int类型；
	int a1{ 1 };
	cout << "检查a1的数值类型-字节量为" << sizeof( a1 ) << endl;
	//将a1强制转换成long long类型后赋值给a2，此时a2为long long类型；

	函数
函数的定义：
1.函数是一段具有特定功能的代码块，通常用于实现某个功能或计算某个值。
2.函数可以有参数和返回值，也可以没有参数和返回值。
3.函数的定义包括函数名、参数列表、返回类型以及函数体。
函数的声明：返回值类型 函数名(参数类型 参数名,参数类型 参数名,...)
函数的调用：函数名(参数值,参数值,...)
函数的返回值：函数执行后返回给调用者的值。
1.无返回值函数：void 函数名(参数类型 参数名,参数类型 参数名,...)
2.有返回值函数：返回值类型 函数名(参数类型 参数名,参数类型 参数名,...)
3.函数的返回值类型可以是基本数据类型、结构体、类、指针等。

	指针
定义：
指针是一个变量，它存储另一个变量的内存地址。
指针可以用来间接访问和操作变量的值。
指针变量：存放指针的变量，通常使用 * 符号来声明。

nullptr:表示无效指针，指针不指向任何有效的内存地址。
int* ptr = nullptr：表示一个指向整数类型的变量名为ptr的空指针。
&:取地址运算符，用于获取变量的内存地址。
*ptr:解引用运算符，用于访问指针所指向的变量的值。
